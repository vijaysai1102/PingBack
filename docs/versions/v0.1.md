# PingBack v0.1 — Baseline Release

## Goals & Summary

PingBack v0.1 established the initial foundation of the local agent attention layer. The primary goal was to reliably detect when Claude Code reaches a state requiring developer attention (or hits a fatal error) and raise a native desktop notification and optional sound on both Windows and macOS.

## Scope & Functional Requirements

- [x] **Agent Adapter (Claude Code)**:
  - Official Claude hook integration: `Notification`, `StopFailure`, `SessionStart`, `UserPromptSubmit`, `SessionEnd`.
  - `hook-entry` binary forwarding payloads to daemon via local IPC.
  - Setup and configuration automation (`pingback setup` modifies Claude settings cleanly).
- [x] **Local Daemon & IPC**:
  - Background daemon process lifecycle management (`pingback start`, `stop`, `status`).
  - Local IPC: Named pipe on Windows (`\\.\pipe\pingback-ipc`), Unix domain socket on macOS (`~/.pingback/daemon.sock`).
  - Restricted file/pipe permissions and local token-based IPC authentication.
- [x] **Desktop Notifications & Sound**:
  - Native toast notifications (PowerShell/BurntToast fallback on Windows, osascript/terminal-notifier on macOS).
  - Audio feedback with priority levels (HIGH triggers audio + toast, NORMAL triggers toast).
  - Built-in sound asset generation and audio playback.
- [x] **Session Tracking**:
  - Local JSON session persistence tracking active session IDs, working directories, and process states.
  - Zero logging of chat content, conversation history, or terminal dumps.
- [x] **CLI Interface**:
  - `pingback setup`: Automates adapter configuration.
  - `pingback start`: Starts daemon in background.
  - `pingback stop`: Stops running daemon.
  - `pingback status`: Displays daemon health and active sessions.
  - `pingback config`: Inspects and updates user preferences.
  - `pingback uninstall`: Cleans up hooks and daemon registrations.
- [x] **Cross-Platform CI Matrix**:
  - Automated CI running on both `windows-latest` and `macos-latest` (Node.js 20, 22 & 24).

## Out of Scope (Non-Goals for v0.1)

- Cloud synchronization, accounts, remote notifications, web dashboard, telemetry.
- Other agent adapters (Codex, Cursor, Gemini, Copilot — planned for future versions).
- Linux support (Windows and macOS focus for v0.1).

## Technical & Architectural Decisions

- **Adapter Abstraction**: All Claude-specific hooks and payloads isolated in `src/agents/claude/`. The core daemon (`src/core/`) operates on normalized event schemas (`PingBackEvent`).
- **Platform Bridges**: OS-specific notification and audio logic placed behind clean platform interfaces in `src/platform/`.
- **Zero-Config Normal Path**: `npm install -g pingback-cli && pingback setup` configures everything needed out-of-the-box.
